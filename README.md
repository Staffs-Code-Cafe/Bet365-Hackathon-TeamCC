# What is it (in short)?
This is the code repository for Team CC's submission to the Bet365 Hackathon 2024
The hackathon consisted of an api, and 3 endpoints:
- /auth - to get a token
- /fragment - to get sentence fragments using the token
- /validate - to submit the final sentence using the token

The goal was to reconstruct a sentence from the fragments received from the /fragment endpoint, and submit it to the /validate endpoint.
